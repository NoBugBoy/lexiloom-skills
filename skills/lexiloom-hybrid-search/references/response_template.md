## 2. 五维核对结论判定标准

1. **一致（Aligned）**：知识库与本地代码两侧证据充分、完全相符。
2. **代码偏离（Code Divergence）**：知识库生效规范（`APPROVED`）明确要求，但代码实现遗漏分支或逻辑相反。
3. **文档滞后（Doc Outdated）**：代码已演进上线（结合提交记录），知识库文档仍为旧版本，需提请文档管理员更新。
4. **未规范化（Undocumented）**：本地代码有核心业务逻辑，但知识库未检索到对应规范。
5. **待确认（Pending Clarification）**：两端存在二义性，或强依赖未固化的外部运行时配置。

- **严禁泄露凭证**：不得输出任何 API Key、Header 凭据或环境文件内容。
- **不得将推断伪装为原文**：推断逻辑必须明确注明“推测/分析”，不可放在引号引用中。
